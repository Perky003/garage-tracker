Garage Tracker v1
Features: seeded today's jobs; add/edit jobs and task checklists; progress; per-job notes; archive completed jobs and restore history; local autosave; installable PWA support.

Android install steps (after hosting): open HTTPS site in Chrome > menu > Add to Home screen / Install app.
Important: data is saved locally in this browser/device and is not currently synced to ChatGPT or other devices.
